Welcome to the first post on **Network Blog**, built with Hugo and the PaperMod theme.

## Getting started

- Add new posts under `content/posts/`
- Configure the theme in `hugo.toml`
- Preview locally with `hugo server -D`

```bash
hugo server -D
```
